# MMM - Monthly Money Metrics

MMM - это приложения для отслеживания своих расходов/доходов для дальнейшего планирования и прогнозирования своего бюджета сделаный в качестве проекта для учёбы

ЦА - это основная асса населения, которые способны зарабатывать и тратить деньги. 
Основные категорииэто студенты(в том числе другая молодёж у кого низкие доходы и необходимо считать каждую копейку) и люди 30-40 лет, которые имеют семью и необходимость ттщательно следить за всем расходами

Платформы - android, ios, macos, linux, windows

# Сценарии:

## Сценарий 1. Добавление новой транзакции

Предусловие: Пользователь авторизован в приложении (или авторизация не требуется в локальной версии, для локальной версии это не требуется).
Поток:

Пользователь нажимает кнопку «+» или «Добавить расход/доход». - 
Открывается форма с полями:

>сумма

>категория (выпадающий список: «Продукты», «Транспорт», «Развлечения» и т. д.)

>дата (по умолчанию — текущая, можно изменить)

>комментарий (опционально)

>тип (расход/доход)

Пользователь заполняет обязательные поля.
Пользователь нажимает «Сохранить».
Система сохраняет транзакцию в локальную БД(в локалной версии).
Система обновляет сводку на главном экране (баланс, расходы за период).
Показывается Toast «Транзакция сохранена».

### Альтернативы:

> Пользователь не заполнил обязательные поля → Система подсвечивает пустые поля и показывает сообщение «Заполните все обязательные поля».

> Пользователь нажимает «Отмена» → Форма закрывается, данные не сохраняются.

## Сценарий 2. Просмотр и фильтрация транзакций

Предусловие: В БД есть записи.

Поток:

Пользователь находится на экране «История транзакций».

Пользователь нажимает на иконку фильтра.

Открывается панель фильтров с опциями:

> период (за сегодня, за неделю, за месяц, кастомный)

> категория

> тип (только расходы, только доходы, всё).

Пользователь выбирает фильтры и нажимает «Применить».

Система отображает отфильтрованный список транзакций.

### Альтернативы:
> Пользователь сбрасывает фильтры → Система показывает все транзакции.

> По заданным фильтрам нет данных → Система показывает сообщение «Транзакций за выбранный период не найдено».
---

## Сценарий 3. Редактирование транзакции
Предусловие: В БД есть хотя бы одна транзакция.

Поток:

1) Пользователь на экране «История» выбирает транзакцию (длительное нажатие или иконка редактирования).
2) Открывается та же форма, что и при добавлении, но с заполненными данными.
3) Пользователь вносит изменения.
4) Пользователь нажимает «Сохранить».
5) Система обновляет запись в БД.
6) Список транзакций обновляется, показывается Toast «Изменения сохранены».

### Альтернативы:
Пользователь нажимает «Отмена» → Изменения не сохраняются, возвращается к списку.

---
## Сценарий 4. Удаление транзакции
Предусловие: В БД есть хотя бы одна транзакция.

Поток:

1) Пользователь выбирает транзакцию в списке (длительное нажатие).
2) Появляется меню с опцией «Удалить».
3) Пользователь нажимает «Удалить».
4) Система показывает диалоговое окно подтверждения: «Вы уверены, что хотите удалить эту транзакцию?».
5) Пользователь подтверждает.
6) Система удаляет запись из БД.
7) Список обновляется, показывается Toast «Транзакция удалена».

### Альтернатива:
Пользователь отменяет удаление → Диалог закрывается, транзакция остаётся.

# Нефункциональные требования (как работает приложение)
- Производительность: Время отклика UI < 16 мс (60 FPS), запуск приложения < 5 сек на среднем устройстве.
- Память: Потребление RAM не более 150 МБ в активном использовании. Отсутствие утечек при повороте экрана.
- Надёжность: Корректная обработка пустой БД, некорректного ввода, отсутствия места на диске.
- Совместимость: Поддержка API 24-34, корректное отображение на экранах от 4.7 до 6.7 дюймов, адаптация к тёмной теме (если реализуется).
- Безопасность: Данные хранятся локально, доступ к файлам только через SAF,
- отсутствие хардкода паролей.
- Лицензирование: Все библиотеки с открытой лицензией (MIT, Apache 2.0), код выложен в открытый репозиторий

# Критерии приёмки и тестирование
Все сценарии из раздела 2 реализованы и проходят ручное тестирование.
Приложение не крашится при повороте экрана, сворачивании/разворачивании.

UTF-8, разделители).
