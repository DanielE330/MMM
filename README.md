# 💰 MMM — Monthly Money Metrics

> Приложение для отслеживания личных доходов и расходов с поддержкой планирования бюджета.
> Учебный проект на Flutter.

## Реализованные сценарии

### 1. Добавление транзакции
- Кнопка **+** открывает форму
- Поля: сумма (только цифры), категория, дата, комментарий, тип (расход / доход)
- Валидация обязательных полей с подсветкой ошибок
- Toast «Транзакция сохранена» после успешного добавления

### 2. Просмотр и фильтрация
- Экран **История** — полный список транзакций
- Фильтры: период (сегодня / неделя / месяц / все), тип (доходы / расходы / все)
- Активные фильтры отображаются чипами с возможностью сброса
- Сообщение «Транзакций за выбранный период не найдено» при пустом результате

### 3. Редактирование транзакции
- Нажатие на карточку открывает заполненную форму
- Toast «Изменения сохранены» после обновления

### 4. Удаление транзакции
- Долгое нажатие на карточку в истории → диалог подтверждения
- Кнопка «Удалить транзакцию» внутри формы редактирования
- Toast «Транзакция удалена» после подтверждения

## Схема БД

**Таблица `transactions`**

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `INTEGER` PK | Автоинкремент |
| `amount` | `REAL` | Сумма (> 0) |
| `category` | `TEXT` | Категория |
| `date` | `TEXT` | ISO 8601 |
| `comment` | `TEXT` | Опционально |
| `type` | `TEXT` | `income` / `expense` |
